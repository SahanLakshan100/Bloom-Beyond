## 📖 About The Project

**Bloom & Beyond** is a charming online gift shop that brings together flowers, cakes, and curated gift hampers in one place. Each product category has its own dedicated page, and a built-in cart page makes the shopping experience smooth and enjoyable.

> 🌐 **Live Demo:** [View on GitHub Pages](https://sahanlakshan100.github.io/Bloom-Beyond/)

---

## ✨ Features

| Feature | Description |
| :--- | :--- |
| 💐 **Flowers Collection** | Browse a beautiful selection of fresh flowers. |
| 🎂 **Cakes Collection** | Discover delicious cakes for every occasion. |
| 🎁 **Gift Hampers** | Curated gift hampers for special moments. |
| 🛒 **Shopping Cart** | Add and review selected items in the cart. |
| ℹ️ **About Us Page** | Learn more about the brand's story. |
| 📞 **Contact Page** | Easy way to reach out for inquiries. |
| 📱 **Responsive Design** | Optimized for desktop, tablet, and mobile. |
| 🚀 **Auto Deployment** | Automated deployment via GitHub Actions. |
